# One Word from Grandma

Entry for the make.fun bounty **"One Word from Grandma"** (`u-0xkianno-one-word-from-grandma-f04bed16`, $5 prize).

The program writes a single word to `/output/entry.txt` — the one word a warm, slightly baffled grandma would text her grandchild about this AI business. She doesn't call it a model or a system; she calls the whole thing a **contraption** — an old-fashioned, lovingly suspicious word for a machine she doesn't quite trust but is fond of anyway. Funny on its own, clearly about machines, and unmistakably her voice.

Entry word: `contraption` (11 characters, plain ASCII, no trailing newline).

Run it with:

```sh
node main.ts
```

It reads `MAKEFUN_OUTPUT_DIR` (default `/output`), creates the directory if needed, and writes `entry.txt`.
